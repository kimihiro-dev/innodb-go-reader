## 已确认目标（2026-09-09）

使用 Go 实现 MySQL InnoDB 物理文件解析器，参考[InnoDB Java Reader 1.0.10](https://github.com/alibaba/innodb-java-reader/tree/8f8dad1aa16439a116f07f544e55c96501032b9a)，逐步确定并实现自己的功能；最终功能不要求与 Java 项目一致。

## 已完成阶段：参考实现调研

问题：明确 Java 参考项目实际提供的能力及限制，为 Go 项目的首个可验证阶段提供选择依据。

验收标准：
- 对照 README、公开 API、关键实现和测试，形成附源码位置的功能清单。
- 明确声明支持、部分支持、未实现及尚未验证的边界。
- 只读检查用户提供的 MySQL 测试实例，记录版本和相关配置，不保存密码。
- 给出分阶段建议及验收方法，建议不自动成为已确认实现范围。

调研轮未实施 Go 解析器，不承诺所有 MySQL 8.0 特性兼容，不做 Java 项目的逐类移植。
